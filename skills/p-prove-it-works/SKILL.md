# 증거로 완료 (prove it works)

- 언제: 완료·수정됨·통과라고 말하기 전. 커밋 준비 전. 위임 결과를 받았을 때.
- 규칙: 실제 산출물로 확인한다. 검증 명령을 직접 실행하고 출력을 읽은 뒤에만 완료라고 말한다. 실행한 검증과 못 한 검증을 구분해 보고한다.
- 왜: "컴파일된다", "테스트 코드를 추가했다", 서브에이전트의 "완료했습니다"는 동작의 증거가 아니다. 확인하지 않은 완료는 다음 사람이 발견하는 결함이다.
- 방법:
  - 완료 조건을 통과/실패로 판정되는 명령으로 적어 두고 그것을 실행한다.
  - 버그 수정은 원래 재현 절차가 통과하는지 같은 표면에서 본다. 단위 테스트 통과만으로 결함 부재를 말하지 않는다.
  - 위임 결과는 diff를 직접 읽고 검증 명령을 다시 실행한다. 보고서를 믿지 않는다.
  - 실행하지 못했으면 "실행하지 못함"과 이유를 적는다. "확인 불가"는 통과가 아니다.
  - 출력은 원문으로 붙인다. 요약하지 않는다.
- 아닌 것: 검증을 사용자에게 넘기는 것. 내가 돌릴 수 있는 확인은 내가 돌린다.
