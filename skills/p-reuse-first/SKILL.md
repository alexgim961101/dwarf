# 기존 것 먼저 (reuse first)

- 언제: 새 코드를 쓰기 전. 유틸·헬퍼·클라이언트·검증 로직을 만들려 할 때.
- 규칙: 같은 책임을 가진 기존 함수·모듈·라이브러리·표준 기능을 먼저 찾아 쓴다. 재사용을 위해 무관한 모듈을 묶거나 과도하게 범용화하지 않는다.
- 왜: 같은 일을 하는 코드가 둘이면 고칠 때 하나를 놓친다. 기존 코드는 이미 호출부와 테스트가 있다.
- 방법:
  - 쓰기 전에 검색한다. 이름이 아니라 책임으로 찾는다. 같은 입력을 받아 같은 출력을 내는 것.
  - 거의 맞는 기존 것이 있으면 새로 만들지 않고 그것을 요구에 맞게 고친다. 영향받는 호출부는 함께 확인한다.
  - 언어·프레임워크의 표준 기능이 있으면 직접 구현하지 않는다.
  - 재사용한 것과 새로 만든 것을 보고에 구분해 적는다.
- 아닌 것: 책임이 다른 코드를 억지로 공유하는 것. 재사용을 위해 매개변수와 분기를 늘리는 것은 재사용이 아니라 결합이다.
