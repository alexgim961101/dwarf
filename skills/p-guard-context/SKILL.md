# 컨텍스트 보호 (guard the context)

- 언제: 긴 파일이나 큰 출력을 읽어야 할 때. 여러 파일을 훑어야 할 때. 같은 내용을 두 번 읽으려 할 때.
- 규칙: 대량 읽기는 explorer에게 맡기고, 메인에는 포인터(경로, 줄 범위, 명령)와 요약만 남긴다. 긴 출력은 파일로 보내고 필요한 부분만 읽는다.
- 왜: 컨텍스트가 차면 앞의 지시와 결정이 밀려난다. 메인 세션의 컨텍스트는 판단에 써야 한다.
- 방법:
  - 어디를 봐야 하는지 모르는 넓은 탐색은 explorer brief로 보낸다. 어디인지 아는 좁은 읽기는 직접 한다.
  - 파일을 전체로 읽지 않고 필요한 범위만 읽는다. 명령 출력은 `head`, `grep`, 파일 리다이렉트로 줄인다.
  - 위임 결과를 그대로 붙이지 않는다. 요약하고 근거만 인용한다.
  - 같은 파일을 다시 읽어야 하면 앞에서 왜 기록해 두지 않았는지 돌아본다.
- 아닌 것: 짧은 파일 하나를 읽는 데 explorer를 띄우는 것. 위임에도 비용이 있다.
