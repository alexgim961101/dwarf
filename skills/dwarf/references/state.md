# 상태 파일

playbook 진행 상태의 기록. todo 도구 대신 이 파일을 쓴다. 세션이 끊기거나, 다른 세션이나 무인 실행(`headless.md`)이 이어 갈 때 여기서 이어 갈 단계를 찾는다.

## 위치

- 작업마다 디렉토리 하나. `<작업 디렉토리>/.docs/dwarf/<날짜>-<주제>/state.md`. 작업 디렉토리는 세션을 시작한 디렉토리, `<날짜>`는 작업을 시작한 날 `YYYY-MM-DD`, `<주제>`는 영문 kebab-case.
- 한 작업 디렉토리에서 여러 세션이 각자 다른 작업을 동시에 할 수 있다. 그래서 작업마다 따로 둔다.
- 이 작업의 관문 기록(`gate`, `gate.md`), 무인 실행 보고(`report.md`, `headless.md`), bug-fix 후보 patch(`candidates/`)도 같은 디렉토리에 둔다.

## 형식

```
playbook: bug-fix
status: running
delegation: 사용 안 함
목표: 재시도할 때 주문이 두 번 생기는 결함 수정

- [x] 1. 원인
- [ ] 2. 해결안 후보
- [ ] 3. 해결안 시험 — skip: 변경 없음 요청
- [ ] 8. 보고 뒤 정리
```

| 줄 | 값 |
|---|---|
| `playbook` | 매칭한 playbook. 맞는 것이 없으면 `없음`과 이유 |
| `status` | `running` 진행 중. `waiting` 사용자 답이 있어야 이어 갈 수 있음(관문 보고, 질문, 원인 미확정 멈춤). `done` 요청을 끝냄. 멈춤 요청을 그 단계까지 마친 것도 `done` |
| `delegation` | 라우터 실행 1의 선택. `사용 (매핑대로)` 또는 `사용 안 함` |
| `목표` | 요청을 한 줄로. 다른 세션이 이어 갈 작업을 고를 때 본다 |
| 단계 | playbook의 번호 단계를 그대로. 마지막 항목은 라우터 실행 8(보고 뒤 정리). 단계 안의 작업 단위(feature 7단계)는 그 단계 아래 들여쓴다 |

## 쓰기

- playbook을 연 직후 만든다. 새 작업이면 새 디렉토리에 만들고, 이어 가는 작업이면 그 디렉토리의 파일을 고친다.
- 다른 작업의 디렉토리는 읽기만 한다. `done`이어도 덮어쓰지 않는다. 같은 이름의 디렉토리가 이미 있는데 이어 가는 작업이 아니면 주제를 바꿔 만든다.
- 단계를 끝내면 `[x]`. 이번 요청에서 하지 않을 단계는 지우지 않고 `skip: 이유`를 붙인다. 멈춰서 아직 하지 않은 단계는 `[ ]`로 둔다.
- 턴을 끝내기 전에 `status`를 쓴다.
- 보고서·스펙 같은 결과물은 여기 적지 않는다. 그 문서의 경로만 단계 옆에 적는다.

## 이어 가기

- 요청이 진행 중 작업의 연장("진행", "고쳐", "후보 A로")이고 그 작업의 `status`가 `waiting`이나 `running`이면, 그 playbook을 열고 `status`를 `running`으로 바꾼 뒤 `[x]`도 skip도 아닌 첫 단계부터 한다. 앞 단계는 다시 하지 않는다. 앞 단계 결과가 세션에 없으면 단계 옆에 적힌 문서(spec.md, report.md, 관문 기록)에서 읽는다.
- 어느 작업인지. 이 세션에서 다룬 작업이면 그 디렉토리다. 아니면 `.docs/dwarf/*/state.md` 중 `status`가 `waiting`·`running`인 것의 `목표`를 요청과 맞춘다. 맞는 것이 둘 이상이거나 애매하면 디렉토리·목표·status를 보이고 고르게 한다. 무인 실행이면 멈추고 보고에 그 목록을 쓴다.
- 이 세션에서 다루지 않은 `running` 작업은 다른 세션이 지금 진행 중일 수 있다. 이어 가기 전에 사용자에게 확인한다.
- `새 작업`이거나 요청이 연장이 아니면 재매칭하고 새 디렉토리에 쓴다.
- 다른 세션에서 이어 갈 때 관문은 이 세션에서 다시 기록한다. hook은 다른 세션이 남긴 관문 기록을 믿지 않는다(`gate.md`). 승인이 필요했던 단계면 `pending`으로 쓰고, 지금까지의 결과와 이어 갈 단계를 짧게 보고해 답을 받은 뒤 `approved`로 바꾼다. 같은 세션이면 다시 받지 않는다.
