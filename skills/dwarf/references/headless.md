# 무인 실행

지금은 답할 사람이 없고, 답이 나중에 이어 가는 실행(`claude -p --resume`이나 대화형 세션에 이어서 넣는 요청)으로 오는 실행. eval의 `run.sh`와 파이프라인이 이렇게 돌린다.

## 알아보기

- 실행하는 쪽이 시스템 프롬프트(`--append-system-prompt`)나 요청에 무인 실행이라고 적는다. eval의 `run.sh`가 그렇게 한다.
- 적혀 있지 않아도 Claude Code에서 `AskUserQuestion` 도구가 없으면 무인 실행이다. `claude -p`가 그렇다. 이때 `Agent`는 `Task`라는 이름으로 보인다.
- 다른 harness는 적혀 있을 때만.

## 묻지 않는다

- 위임 여부(라우터 실행 1)는 묻지 않고 매핑대로 쓴다. 요청에 정해져 있으면 그대로.
- 매핑 파일이 없으면 `agents.md`의 기본값을 쓰고 파일은 쓰지 않는다. 답변에 한 줄 적는다.
- 실행 중에 하나씩 묻지 않는다. 해석으로 진행할 수 있으면 해석을 적고 진행한다. 결과가 크게 달라지는 질문은 모아서 멈출 때 보고에 쓴다.

## 상태와 보고

- 상태 파일은 `state.md` 규칙대로 쓴다. 실행하는 쪽은 턴이 끝났을 때 `status`가 `waiting`이면 보고를 사용자에게 전하고 답을 다음 실행(`--resume`)의 요청으로 넘긴다. `done`이면 끝낸다.
- 턴을 끝내기 전에 이번 보고(마지막 답변과 같은 내용)를 `<작업 디렉토리>/.docs/dwarf/report.md`에 덮어쓴다. 대화형 세션으로 돌리는 쪽(herdr 등)은 화면 대신 이 파일로 보고를 받는다.
